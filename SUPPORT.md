# Support

This project is released as-is by the operator of this GitHub account.
There is no formal support channel, no SLA, and no expectation of timely
responses.

## Where to get help

1. Read `README.md`, `ARCHITECTURE.md`, `TROUBLESHOOTING.md`, and
   `SECURITY.md`.
2. Search [existing issues](../../issues) for a similar report.
3. If you find a bug or want a feature, [open an issue](../../issues/new/choose).
4. For security issues, follow the private coordination flow described in
   `SECURITY.md`. Do not file a public issue.

## What to include

When filing an issue:

- exact version (`hermes-antigravity-acp --version`);
- Python version (`python3 --version`);
- Hermes version (`hermes --version`);
- Antigravity CLI version (`agy --version`);
- operating system and architecture (`uname -a`);
- minimal reproduction;
- sanitized logs (no tokens, no OAuth responses, no prompts).

## What NOT to expect

The maintainer may close, defer, or decline issues without response.
External contributors are welcome to open pull requests; see
`CONTRIBUTING.md` for the workflow.
